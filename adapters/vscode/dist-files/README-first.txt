md-preview-kit  ―  Markdown の図を表示する VS Code 拡張

■ 入れかた
  1. この install.bat をダブルクリックしてください。
     （zip の中身を直接開いたままでは動きません。必ず解凍してから）

  2. 終わると sample.md が VS Code で開きます。
     VS Code の中で  Ctrl+Shift+V  を押すと、図の入ったプレビューが出ます。

■ 書きかた
  sample.md が見本と説明書を兼ねています。真似して書けば図が出ます。

■ 詳しい説明・困ったとき
  INSTALL.md（VS Code で開いて Ctrl+Shift+V で読むと見やすい）

■ VS Code がまだ無い場合
  https://code.visualstudio.com/ からインストールしてください。
  （インストール時の選択肢は既定のままで大丈夫です）
