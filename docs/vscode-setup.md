# md-preview-kit の入れ方（VS Code / Windows）

Markdown（`.md`）の中に書いた図が、そのまま図として表示されるようになります。
**この拡張が行うのは表示だけ**で、プログラムを実行したり外部に通信したりはしません。

## 0. 配布物の中身

| ファイル | 何か |
|---|---|
| **`install.bat`** | **これをダブルクリックすれば導入完了**（§2） |
| `md-preview-kit-x.y.z.vsix` | 拡張本体。`install.bat` が自動で使う |
| `はじめに読む.txt` | 最小限の手順（3行） |
| `INSTALL.md` | この文書 |
| `sample.md` | **書き方の見本と仕様書**。動作確認にも使う |
| `sample.drawio.svg` / `sample.fig.svg` | `sample.md` が参照している図 |

## 1. 用意するもの

- **VS Code**（未導入なら <https://code.visualstudio.com/> からダウンロードしてインストール）
  - インストール時の選択肢はすべて既定のままで問題ありません
  - 表示を日本語にしたい場合は、拡張の検索欄で `Japanese Language Pack` を入れます
- 他に必要なもの（Node.js、Python など）は**ありません**

**フォルダは Windows のローカル（`C:\` の下、デスクトップやドキュメントなど）に置いてください。**
ネットワークドライブや共有フォルダ（`\\` で始まる場所）に置くと、md を保存しても
プレビューが自動更新されないことがあります。

## 2. 入れる（`install.bat` をダブルクリック）

zip を**解凍してから**、中の **`install.bat`** をダブルクリックします。
（解凍せず zip の中身を直接開くと動きません）

- 途中で「作図用の拡張も入れますか？」と聞かれます。**draw.io で図を描く**なら `y` を
  入力してください（後から入れてもかまいません）
- 「完了しました」と出たら閉じてよいです

> Windows が「WindowsによってPCが保護されました」等の警告を出した場合は、
> `詳細情報` → `実行` で進めてください（バッチファイルは中身をメモ帳で確認できます）。

### 手作業で入れる場合（`install.bat` が使えないとき）

1. VS Code を開く
2. 左端の拡張アイコン（または `Ctrl+Shift+X`）
3. 拡張ビュー右上の **`...`（横三点）** → **`VSIX からのインストール...`**
4. `md-preview-kit-x.y.z.vsix` を選ぶ
5. 右下に「再読み込み」が出たら押す

> **注意**: vsix ファイルをどこかのフォルダにコピーしても入りません。
> 必ず `install.bat` か上の手順で入れてください。

## 3. 動作確認

`sample.md` を VS Code で開き、**`Ctrl+Shift+V`** を押します
（**`Ctrl+K` を押してから `V`** なら、左に文章・右にプレビューが並びます）。

以下が出ていれば正常です。

- [ ] §11 mermaid のフローチャート・シーケンス図（VS Code 1.121 以降なら標準で出ます。
      出ない場合は §4 の拡張を入れてください）
- [ ] §12 棒グラフ・折れ線・円グラフ
- [ ] §13 draw.io の図（画像として表示）
- [ ] §14 ラダー図（デバイス名にマウスを乗せると同じデバイスが光る）
- [ ] §15 回路図（画像として表示）
- [ ] §16 タイミング図（波形が描かれている）
- [ ] §18 に**赤いエラーメッセージ**が出ている ← これは**わざと壊した例**で、正常な動作

## 4. 一緒に入れると便利な拡張

拡張ビュー（`Ctrl+Shift+X`）で名前を検索してインストールします。

| 拡張名 | 何ができるか | 要否 |
|---|---|---|
| **Draw.io Integration**（hediet） | `.drawio.svg` を VS Code の中で作図・編集できる | 自分で作図するなら（`install.bat` で `y` を選んだ場合は導入済み） |
| **Markdown Preview Mermaid Support** | ` ```mermaid ` を図にする | **VS Code 1.121 以降は不要**（標準機能）。それより古い場合だけ |

入れても、**md の書き方は変わりません**。

## 5. 普段の使い方

| やること | 操作 |
|---|---|
| プレビューを開く | `Ctrl+Shift+V` |
| 文章とプレビューを左右に並べる | `Ctrl+K` → `V` |
| 更新 | **保存すると自動**（左右に並べているときは入力に追従） |

書き方は **`sample.md` を見ながら真似るのが最短**です。基本の Markdown 記法から
各図の書式、公式ドキュメントへのリンクまで、あのファイル1枚にまとまっています。

**AI（ChatGPT・Claude など）に書かせる場合**は、`sample.md` を読ませて
「この環境で使える書式で書いて」と指示すれば、対応している図・使えない書き方を
踏まえて書いてくれます。

## 6. 更新（新しいものを受け取ったとき）

新しい zip を解凍して、また **`install.bat` をダブルクリック**するだけです
（上書きされます）。古いものを消す必要はありません。

反映されないときは、VS Code で `Ctrl+Shift+P` → `Developer: Reload Window`。

やめるときは、拡張ビューで `md-preview-kit` を探して歯車 → `アンインストール`。

## 7. うまくいかないとき

| 症状 | 対処 |
|---|---|
| `install.bat` が「VS Code が見つかりません」と言う | VS Code が未導入か、インストール時に PATH 追加を外した可能性。§2 の「手作業で入れる場合」で入れる |
| ウィンドウが一瞬出て消える | zip を解凍せずに実行している。**解凍してから**実行する |
| 図にならず、文字のまま表示される | 拡張が入っていない／有効になっていない。`Ctrl+Shift+P` → `Developer: Reload Window` を試し、それでも駄目なら §2 の手作業手順で入れ直す |
| 保存してもプレビューが変わらない | ファイルが `\\` で始まる場所（ネットワーク・共有フォルダ）にある。ローカルにコピーして開く |
| mermaid だけ図にならない | VS Code が 1.121 より古い（`ヘルプ` → `バージョン情報`）。VS Code を更新するか、§4 の拡張を入れる |
| 図の枠は出るが中身が空 | プレビューを開いた状態で `Ctrl+Shift+P` → `Developer: Open Webview Developer Tools` → `Console` のエラー内容を添えて連絡してください |
| `![](...)` の画像が出ない | 画像のパスは **md ファイルから見た相対位置**。`sample.md` なら同じフォルダに `sample.drawio.svg` が必要 |
| グラフの目盛りを関数で整形したい | できません（§8 の理由により仕様）。関数を使わない設定項目で書く |

## 8. 安全性について

配って開いてもらう md を前提に、意図的に線を引いてあります。

- **図の指定（フェンスの中身）はデータとして読むだけで、実行しません。**
  `eval` の類を一切使っていません（同種の実装で任意コード実行の脆弱性報告が出ているため、
  原理的に踏まない作りにしてあります）。その代わり「設定に関数を書けない」という
  制約がありますが、これは仕様です
- **外部と通信しません。** 描画に使うライブラリは拡張に同梱されており、
  インターネットに繋がっていなくても動きます
- **回路図（`.fig.svg`）を作るときの Python も実行していません。**
  表示しているのは出来上がった画像だけです
